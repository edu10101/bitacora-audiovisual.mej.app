## ✨ Funcionalidades

- 📅 **Calendario semanal** con navegación entre semanas (anterior / siguiente).
- 👨‍🏫 **Tarjetas por docente** con grupo, aula y equipo requerido (📹 🔊 💻).
- 🟢 **Aulas libres** por bloque horario.
- 🔴 **Indicador de "Horario Lleno"**.
- 📝 **Bloc de notas del administrador** (se guarda en `localStorage`).
- 🔐 **Login de administrador** (usuario: `admin`, contraseña: `prepa123`).
- ➕ **Modal para agendar préstamos** con:
  - Selección de fecha.
  - Selección de horario.
  - Autocompletado de docentes.
  - Selección de grupo según el docente.
  - Selección de aula.
  - Notas opcionales.
  - Equipo requerido (proyector, bocina, laptop, TV).
